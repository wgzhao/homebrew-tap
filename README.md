# Homebrew tap for lingbox

[lingbox](https://github.com/wgzhao/ling-box) (玲珑盒) is a cross-platform CLI toolbox for developers: URL/base64/bcrypt/QR/password utilities, terminal image display, and PDF rendering.

## Install

```sh
brew tap wgzhao/tap
brew install lingbox
```

## Usage

```sh
lingbox --help
```

## Note

The same formula is also prepared for submission to [homebrew/homebrew-core](https://github.com/Homebrew/homebrew-core), which requires the repository to gain some traction first (see Homebrew's [notability policy](https://docs.brew.sh/Adding-Software-to-Homebrew#well-knownness)).
